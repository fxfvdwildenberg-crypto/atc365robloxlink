# ATC365 Access Link

Make a website where people with a specific role in my Discord server can access a button to open a link, make sure that they cannot see the link itself, only the link with a button to open the link

Make sure that ONLY people with a specific role can access the link

The website name should be ATC365

Users probably have to give a Discord bot permissions to check the roles in a specific server
